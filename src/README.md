# Source Code

This directory contains the Java source code for the **Vehicle Rental System**. The application is organized into multiple packages, with each package responsible for a specific part of the system.

The structure follows object-oriented design principles to separate the vehicle model, booking and payment logic, user management, business services, user interface, and supporting components.

---

## Directory Structure

```text
src/
  Booking/
  Exceptions/
  Interfaces/
  Service/
  Users/
  Vehicles/
    enums/
  VehicleStyle/
  rentalfx/
  UI/
  Test/
  Main.java
```
